# ML Regression Model

This project is a Machine Learning regression model built using Python which can predict car's price based on their past usage , facility and brand value .

## Features
- Data Preprocessing
- Handling missing values
- Feature scaling (numerical features) / Encodeing (Catagorial features)
- Model Training
- Model Evaluation

## Library Used
- numpy
- pandas
- matplotlib
- scikit-learn

## Model Used
- Regression Model (Linear Regression)
